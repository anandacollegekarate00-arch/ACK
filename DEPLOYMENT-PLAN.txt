5. TROUBLESHOOTING GUIDE

| Issue                  | Cause                              | Fix                                                     |
|------------------------|------------------------------------|---------------------------------------------------------|
| Site won't load        | Wrong Firebase URL                   | Open Firebase Console → Hosting → visit site            |
| Features broken        | Firebase APIs disabled               | Console → Project Settings → APIs → Enable Auth/Firestore|
| ENOENT error           | Wrong npm directory                  | cd C:\Users\User\Desktop\ACK WEB && npm run build       |
| Cloudflare build failed| Node version mismatch                | Set Node version to 18 or 20 in Settings                |
| Features not working   | Supabase not configured              | Run database-schema.sql in Supabase SQL Editor          |
| PWA not installing     | Missing manifest/icons               | Verify vite.config.ts PWA config + assets exist          |
| Styles not applying      | Tailwind not built                   | Run npm run build, upload dist/                         |

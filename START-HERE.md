## 🆘 Emergency Help

### If Nothing Works

1. Check browser console (F12) for errors
2. Verify Supabase project is active
3. Make sure you ran the ENTIRE database-schema.sql
4. Try in a different browser or incognito mode
5. Re-read QUICKSTART.md step by step

### Common First-Time Mistakes

❌ Didn't run the complete database-schema.sql  
❌ Copied wrong Supabase key (service_role instead of anon public)  
❌ Forgot to create profile record after creating user  
❌ Didn't check "Auto Confirm User" when creating account  
❌ Supabase project is paused (free tier pauses after 7 days inactivity)

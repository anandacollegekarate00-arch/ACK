## 🐛 Troubleshooting

### **"Failed to load"** error?

- Make sure you have internet (needs to load React from CDN)
- Try a different browser

### **Can't login?**

- Check your Supabase credentials
- Make sure your Supabase project is active
- Verify the URL and key in the file are correct

### **No data showing?**

- Check your Supabase tables exist
- Verify you have the right database schema
- See `DATABASE-SCHEMA.md` for table structure

### **Blank white screen?**

- Open browser console (F12)
- Check for errors
- Make sure JavaScript is enabled
